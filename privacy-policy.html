Privacy Policy — Journal

Last updated: 2026-08-26.

Journal is a personal journaling app built and used by a single developer (Jennifer Walker) for her own use. It is not distributed or offered as a service to the public.

What data this app accesses

Journal stores its entries as a single file in the signed-in user's own Google Drive. It uses Google's drive.file OAuth scope, meaning it can only see and modify files it created itself — it cannot browse, read, or modify any other files in the user's Drive.

A companion backup script uses a separate, read-only (drive.readonly) OAuth client to download a copy of that same journal file to a local folder on the developer's own computer, purely as a personal backup measure.

What data this app does not do

This app does not have a server or backend. It does not transmit, sell, or share any data with third parties. Journal entries and their backups never leave Google Drive and the developer's own local computer.
